# ATLAS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build ATLAS anti-proxy attendance backend (Go) with minimal static PWA, per approved spec.

**Architecture:** Stdlib net/http Go API behind Nginx; Postgres for truth, Redis for TOTP-step cache and scan rate limits; static web/ PWA polling 5s QR codes; local-disk uploads behind S3-ready Storage interface.

**Tech Stack:** Go >=1.23, PostgreSQL 16, Redis 7, Nginx (alpine), vanilla HTML/JS PWA, Docker Compose.

## Global Constraints

- Go API container memory limit: 100MB.
- Postgres memory limit: 1024MB.
- Redis memory limit: 128MB.
- Nginx memory limit: 32MB.
- TOTP: RFC6238 SHA1, 6-digit, period 5s, accept +-1 step.
- Geofence default radius: 30 meters, Haversine gate, fail-closed.
- Scan rate limit: 10 requests/min per IP (Redis INCR+EXPIRE).
- JWT HS256 expiry 8h; bcrypt cost 10.
- Absence uploads: PDF/JPEG/PNG only, max 5MB, MIME-sniffed, local disk MVP with S3 env vars reserved.
- One attendance mark per (student_id, session_id), idempotent re-scan.
- Every mutation writes audit_logs and relevant notification.
- No web push, no email digest, no Cloudflare in this build.

```go
package totp

import (
	"crypto/hmac"
	"crypto/sha1"
	"encoding/binary"
	"fmt"
	"time"
)

const Period = 5

func counter(t time.Time) uint64 { return uint64(t.Unix() / Period) }

func hotp(secret []byte, c uint64) string {
	var b [8]byte
	binary.BigEndian.PutUint64(b[:], c)
	m := hmac.New(sha1.New, secret)
	m.Write(b[:])
	s := m.Sum(nil)
	o := s[len(s)-1] & 0x0f
	v := binary.BigEndian.Uint32(s[o:o+4]) & 0x7fffffff
	return fmt.Sprintf("%06d", v%1000000)
}

func Generate(secret []byte, t time.Time) string { return hotp(secret, counter(t)) }

func Valid(secret []byte, code string, t time.Time) bool {
	c := counter(t)
	return code == hotp(secret, c-1) || code == hotp(secret, c) || code == hotp(secret, c+1)
}
```

```go
package geo

import "math"

func HaversineM(lat1, lng1, lat2, lng2 float64) float64 {
	const r = 6371000.0
	dLat := (lat2 - lat1) * math.Pi / 180
	dLng := (lng2 - lng1) * math.Pi / 180
	a := math.Sin(dLat/2)*math.Sin(dLat/2) +
		math.Cos(lat1*math.Pi/180)*math.Cos(lat2*math.Pi/180)*math.Sin(dLng/2)*math.Sin(dLng/2)
	return 2 * r * math.Asin(math.Sqrt(a))
}
```
